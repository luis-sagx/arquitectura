Servidor REST de conversión de unidades

API Jakarta RESTful Web Services (JAX-RS) para autenticación, catálogo y conversión de longitud, masa y temperatura.

La raíz de la API es /api. Las operaciones protegidas reciben el token como Authorization: Bearer <token>.

  • POST /api/auth/login: iniciar sesión.
  • POST /api/auth/recover: recuperar clave.
  • GET /api/catalog/categories: consultar categorías.
  • GET /api/catalog/categories/{categoria}/units: consultar unidades.
  • POST /api/conversions: convertir una unidad.

Consulta README.md en el proyecto para ver ejemplos JSON, configuración y códigos de respuesta.
